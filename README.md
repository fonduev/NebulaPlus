# 🪐 NebulaPlus

**NebulaPlus** es el mod complementario oficial para **Nebula Launcher**, desarrollado y mantenido por **NebulaDevStudios**.

Transforma la experiencia dentro de Minecraft con un menú principal 3D interactivo, lobbies vivos con escenas dinámicas del juego, cosméticos, soporte para shaders y una interfaz moderna con esquinas redondeadas basada en Compose.

---

## 🚀 Características principales
- 🌲 **Lobby 3D en tiempo real**: Menú principal interactivo donde tu personaje camina sobre escenas del mundo de Minecraft.
- 🎨 **Interfaz Cósmica Moderna**: Interfaz gráfica vectorizada con tecnología Compose y OneConfig.
- ⚡ **Optimización y Estabilidad**: Totalmente compatible con Sodium, Iris Shaders y Fabric moderno.
- 🛡️ **Privacidad**: Sin telemetría intrusiva ni servidores patrocinados obligatorios.
